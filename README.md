# TRASA · Operación Ojo Verde

Web pública del concurso fotográfico. El backend utiliza Cloud Firestore y Authentication de Firebase.

1. Introduce los valores públicos de tu proyecto Firebase en `config.js`.
2. Publica en GitHub Pages desde la rama `main` y carpeta raíz.
3. Configura las reglas, el usuario administrador y las pruebas **en Firebase**, utilizando el paquete privado entregado por separado.

⚠️ No publiques en este repositorio las contraseñas, los secretos de Firebase, el archivo JSON de las pruebas antes del evento ni el ZIP privado de configuración. Una `firebaseConfig` web no es una contraseña.
